# 阿里巴巴（中国）有限公司

# 淘天 Agent

【岗位职责】

1. 重塑消费者体验：建设大模型智能化比价辅助决策、AI 消费者智能问答助手等多元 AI 工具，提高用户购物体验，并进一步探索 AI Native 的新消费者产品形态。
2. 赋能商家智能化运营：基于大模型调度多领域智能体，实现智能客服、采购寻源、内容生成、直播运营等全链路提效，赋能千万商家。
3. 构建平台级技术基建：开发 AI 代码生成工具提升研发效率，打造面向运营小二的智能提效平台，探索面向全体企业员工办公场景的智能体架构。

【岗位要求】

1. 本科及以上学历，计算机科学、软件工程、人工智能相关专业优先。
2. 掌握 Python/Java/Go/C++ 等编程语言开发，具备扎实的算法与数据结构基础。
3. 具备 Agent 系统开发经验，掌握 LangChain/LlamaIndex/AutoGen 等框架及实现原理，能够设计高可用、高扩展性的大模型/Agent 工程架构。
4. 掌握 Prompt 工程、RAG、Tool Calling、Context Engineering 等 AI 应用关键技术。
5. 能够进行工具集成，掌握 OpenAPI、RPC、MCP 等协议实现方案。
6. 了解机器学习、深度学习框架（PyTorch/TensorFlow），有 Transformer 等模型实战经验优先。
7. 具备问题/价值驱动的探索精神和优秀的问题解决能力。
8. 敢于创新，主动探索 AI 新技术/新范式在商业场景中的应用边界。
9. 对 AI 技术充满热情，具备快速学习的能力，持续关注和学习 AIGC 前沿技术研究。

【加分项】

1. 有数据工程、模型微调/后训练、模型评测经验的同学优先。

## 知识点（可继续补充）

### 业务场景
- **淘天 Agent**：面向电商（淘宝/天猫）业务的 Agent 应用岗位。
- **消费者体验**：大模型智能化比价辅助决策、AI 消费者智能问答助手。
- **AI Native 产品**：产品形态从底层就基于 AI 设计，而非事后叠加 AI 功能。
- **商家智能化运营**：智能客服、采购寻源、内容生成、直播运营等全链路提效。
- **平台级技术基建**：AI 代码生成工具、面向运营小二的智能提效平台、办公场景智能体架构。

### Agent 框架与关键技术
- **LangChain**：主流的 LLM 应用开发框架（Chain/Agent 编排）。
- **LlamaIndex**：专注于数据接入与 RAG 检索的框架。
- **AutoGen**：微软的多 Agent 对话协作框架。
- **Prompt 工程**：设计高效提示词引导模型行为。
- **RAG**：检索增强生成，结合外部知识。
- **Tool Calling / Context Engineering**：工具调用与上下文工程。
- **高可用、高扩展架构**：Agent 工程系统的容量设计与容错。

### 协议与集成
- **OpenAPI**：开放的 HTTP API 规范，标准化的接口定义。
- **RPC（Remote Procedure Call）**：远程过程调用，服务间通信。
- **MCP（Model Context Protocol）**：模型上下文协议，标准化模型与外部工具的接入。

### 模型与训练
- **PyTorch / TensorFlow**：两大主流深度学习框架。
- **Transformer**：现代大模型的基础架构（Attention 机制）。
- **模型微调 / 后训练**：基于领域数据适配任务。
- **模型评测**：量化评估模型/Agent 效果。
- **AIGC**：AI 生成内容（文本、图像、视频等）。

### 数据工程
- **数据工程**：数据采集、清洗、加工，为模型训练与业务分析提供高质量数据。
