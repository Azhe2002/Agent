# AI 技术应用

【岗位职责】

1. 参与实际产品的 AI 大模型与 AI 算法在各类业务场景中的应用开发、集成与迭代优化。
2. 参与 AI 大模型与 AI 算法应用相关的需求分析、模型微调、RAG 检索，提升模型在各类场景下的应用效果。
3. 参与产品、数据、业务等团队协作，建立 AI 大模型与 AI 应用相关的数据分析、效果评估、问题定位与持续优化，提升用户体验和业务价值。

# AI Agent 开发

【岗位职责】

1. 深耕记忆管理、自主决策、代码生成技术，持续提升 Agent 上下文管理、规划推理和工具调用等核心能力，支撑信息获取、应用生成、代码生成、办公文档、GUI 操控智能体的构建。
2. 面向预训练/后训练构建 Agent 的复杂任务规划、Repo 级长程轨迹交互、多步工具编排等高价值数据生产管线，强化推理深度、决策鲁棒性与复杂场景适应力，拓展智能体能力边界。
3. 探索强化学习与 Agent 的深度融合，构建环境反馈驱动的策略优化机制，提升复杂决策场景的泛化性和准确性。
4. 负责业界前沿技术分析和规划，与领军专家和科研团队合作创新，探索自主演化、多智能体协作、复杂代码生成等 Agent 技术前沿，提升技术竞争力与影响力。

## 知识点（可继续补充）

### AI 技术应用
- **AI 大模型应用开发**：模型在业务场景中的应用开发、集成与迭代优化。
- **模型微调（Fine-tuning）**：在预训练模型基础上用领域数据微调，适配具体业务场景。
- **RAG 检索**：检索增强生成，结合外部知识提升回答质量。
- **效果评估**：数据分析、效果评估、问题定位与持续优化闭环。

### Agent 核心能力
- **记忆管理（Memory Management）**：上下文管理与跨会话记忆能力。
- **自主决策（Autonomous Decision-making）**：Agent 自主规划与决策，不依赖人逐步指示。
- **代码生成（Code Generation）**：面向编码任务的代码产出能力。
- **规划推理（Planning & Reasoning）**：复杂任务的分解、推理与步骤规划。
- **工具调用（Tool Use）**：按需调用外部工具完成具体动作。
- **智能体类型**：信息获取、应用生成、代码生成、办公文档、GUI 操控等。

### 数据与训练
- **预训练 / 后训练（Pre-training / Post-training）**：预训练学习通用能力，后训练（SFT / RL）适配具体任务。
- **复杂任务规划**：把大目标分解为可执行的子任务序列。
- **Repo 级长程轨迹交互**：在代码仓库级别进行长时间、多步的交互与修改。
- **多步工具编排**：多个工具按序或并行编排调用。
- **数据生产管线**：为模型训练产出高价值数据（复杂规划、长程轨迹、多步工具编排等）。

### 强化学习与 Agent
- **强化学习（RL）**：与环境交互，通过奖励反馈优化策略。
- **环境反馈驱动的策略优化**：根据环境/执行结果反馈持续调整 Agent 行为。
- **泛化性与鲁棒性**：跨场景的泛化能力与面对异常/扰动的鲁棒性。

### 前沿方向
- **自主演化**：Agent 在运行中自我改进与演化。
- **多智能体协作**：多个 Agent 分工协作解决复杂任务。
- **复杂代码生成**：大规模、长程、多文件的代码生成。
