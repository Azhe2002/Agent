## 知识点（可继续补充）

### 核心概念
- **AI-native（AI 原生）**：产品/研发流程从底层就围绕 AI 能力设计，而非事后接入 AI。
- **AICRM**：以 AI 能力为核心的企业销售与客户沟通管理系统（CRM = Customer Relationship Management，客户关系管理）。
- **AI Coding**：使用 AI 编程工具（Claude Code、Codex、Cursor 等）完成需求分析、编码、测试、代码审查等研发全流程。

### Agent 架构
- **Agent Runtime**：Agent 的运行引擎，核心能力包括任务规划、上下文管理、工具调用、状态管理、记忆机制、异常处理。
- **任务规划（Planning）**：将复杂目标分解为可执行的子任务序列。
- **上下文工程（Context Engineering）**：管理进入模型的有效上下文，控制长度、优先级与信息密度。
- **工具调用（Tool Use / Function Calling）**：模型按结构化方式请求调用外部函数/工具，是 Agent 执行动作的关键机制。
- **记忆机制**：短期记忆（会话内上下文）与长期记忆（跨会话持久化，如用向量库存储过往经验/偏好）。
- **工作流编排（Workflow Orchestration）**：按固定或动态流程编排多个 Agent/步骤的执行顺序。
- **多 Agent 协作**：多个 Agent 分工完成复杂任务，涉及任务分解、协作调度与结果汇总。
- **MCP（Model Context Protocol）**：模型上下文协议，标准化模型与外部工具/数据源的接入方式。

### RAG 技术体系
- **文档解析**：从 PDF、Word、HTML 等格式中提取文本、表格、图片内容。
- **文本切分（Chunking）**：将长文本切成适合嵌入与检索的片段。
- **Embedding（向量化）**：将文本转换为语义向量。
- **向量检索**：基于向量相似度（如余弦相似度）召回相关片段。
- **混合检索（Hybrid Retrieval）**：关键词（如 BM25）与向量检索结合，兼顾精确匹配与语义匹配。
- **重排序（Re-ranking）**：对召回结果用更强的模型二次排序，提升 Top-K 质量。
- **知识引用**：在回答中标注来源，可溯源、降低幻觉。
- **答案生成**：基于检索到的上下文生成带引用的回答。

### 模型与应用
- **Prompt 设计**：通过提示词引导模型行为。
- **结构化输出（Structured Output）**：约束模型输出为 JSON 等固定格式，便于程序消费。
- **幻觉（Hallucination）**：模型生成与事实不符的内容，需通过检索、引用、约束等手段抑制。

### 工程化与评测
- **生产环境能力**：并发、超时、重试、降级、幂等、监控、日志追踪。
- **Agent 评测体系**：测试数据集、效果评估、过程追踪、日志分析、结果回归。
- **核心指标**：准确性、稳定性、执行效率、Token 消耗、响应延迟。

### 主流大模型
- OpenAI（GPT 系列）、Claude（Anthropic）、Gemini（Google）、DeepSeek、GLM（智谱）。
