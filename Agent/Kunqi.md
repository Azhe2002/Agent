# 北京坤启无限科技有限公司

# AI Agent 研发实习生

【岗位简介】

我们正在寻找一位对 AI Agent（智能体）架构具有深度热情且基础扎实的实习生。你将参与构建下一代 AI 原生应用，深度介入从 LLM 逻辑编排、后端服务化到前端交互的全链路开发。我们不要求你精通所有技术栈，但极其看重你的系统级工程素养、工程化交付能力以及在 AI 领域的自驱动进化速度。

【岗位职责】

1. Agent 业务逻辑开发：参与 AI Agent 核心功能的前后端迭代，协助实现 Agent 的任务规划、工具调用（Tool Use）与长短期记忆管理。
2. 工程化链路维护：负责标准 RESTful API 的设计与实现，支持复杂数据流处理及前端状态同步。
3. 交付与质量保障：在 Git 流转规范下进行协作，编写基础单元测试，利用 Postman/curl 等工具完成端到端接口验证。
4. 系统性能优化：跟进线上问题排查，优化 Agent 响应时延（Latency）与输出稳定性，参与基于 Docker 的容器化部署实践。
5. 前沿技术追踪：探索 AI 应用的最佳实践（如构建更加鲁棒的 Agentic Workflow），推动功能快速原型化并落地。
6. Context Data 数据飞轮：构建 AI 自进化体系，推动核心业务数据沉淀。
7. 应用前端开发：参与产品商业化品牌建设，能熟练使用 React 和 Next.js 进行前端功能的开发，对 PC Web、H5 以及 SEO、GEO 友好型前端建设有经验或有研究兴趣。

【岗位要求】

1. 前端生态：了解 React + TypeScript 体系，有能力构建响应式、高性能的 Web 交互界面。
2. 后端架构：了解 Python（FastAPI/Flask）或 Go，对异步编程、中间件及数据库交互有基本认知。
3. AI Agent 认知：了解主流的 AI Agent 的构建方法，对主流模型、Skills、Tool Call、上下文管理等有一定了解。
4. 工程基本功：熟练掌握 Git 分支管理与协同流程。
5. 熟悉 Linux/Unix 环境，具备基础的 Docker 容器化概念。
6. 具备严谨的接口调试与解决问题能力，有基础的单元测试/集成测试意识。
7. 背景：计算机或相关专业在读（本科/研究生），具备扎实的数据结构、算法及计算机系统原理基础。
8. 核心特质：对 AI 以及构建 AI 应用（AI-Native Apps）拥有极强的持续学习热情和探索精神。
9. 软实力：出色的逻辑思维能力、卓越的责任心，能够对分配的任务实现完整闭环。
10. 实习时间：能保证半年及以上实习期，每周到岗/在线时间不少于 4 天。

【加分项】

1. 有完整的、可演示的 Web 应用或开源项目开发经验。
2. 深度使用过 Cursor、Claude Code 或其他 AI 辅助编程工具。
3. 能够展示在复杂问题面前的 Self-debugging 能力或技术博客记录。

【我们看重】

1. 不仅是 Code，更是 Solution：我们寻找能理解业务需求，并用工程化手段将其转化为稳定功能的 Builder。
2. 闭环意识：不要求你是 Senior，但要求你能沟通、能实现、能自测、能复盘。

## 知识点（可继续补充）

### 角色概览
- **AI 原生应用（AI-Native Apps）**：应用从底层就围绕 AI 设计，而非事后接入 AI 功能。
- **Agentic Workflow**：由 Agent 驱动执行的工作流编排，强调鲁棒性。
- **全链路开发**：LLM 逻辑编排 → 后端服务化 → 前端交互。

### Agent 核心能力
- **任务规划（Task Planning）**：把复杂目标拆解为可执行步骤。
- **工具调用（Tool Use）**：模型按需调用外部工具完成动作。
- **长短期记忆管理**：会话内短期记忆 + 跨会话持久化长期记忆。

### 工程化能力
- **RESTful API**：前后端交互的主流接口规范。
- **数据流处理 / 前端状态同步**：复杂数据在前后端的流转与一致性。
- **测试体系**：单元测试、集成测试、端到端（E2E）接口验证。
- **Git 分支管理与协同流程**：团队协作基础。
- **性能优化**：线上问题排查、响应时延（Latency）与输出稳定性。

### 前后端技术栈
- **前端**：React + TypeScript、Next.js；PC Web、H5 多端；SEO（搜索引擎优化）与 GEO（生成式引擎优化）友好。
- **后端**：Python（FastAPI/Flask）或 Go；异步编程、中间件、数据库交互。

### 数据飞轮
- **Data Flywheel（数据飞轮）**：产品使用产生数据 → 数据反哺模型 → 模型能力提升产品，形成自增强循环。
- **AI 自进化体系**：基于业务数据沉淀持续改进 Agent 能力。

### 基础设施
- **Linux/Unix**、**Docker 容器化**。
- **AI 辅助编程**：Cursor、Claude Code 等 Coding Agent 工具。

### 人才特质
- **Builder 思维**：理解业务需求，用工程化手段转化为稳定功能。
- **闭环意识**：能沟通、能实现、能自测、能复盘。
- **Self-debugging**：独立定位并修复自身代码问题的能力。
