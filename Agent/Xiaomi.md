# 北京小米移动软件有限公司

# AI Agent 研发工程师

【岗位职责】

1. 负责材料研发智能体的需求分析、技术方案设计、工程开发、上线交付及持续运营，对业务效果和系统质量负责。
2. 与材料及制造领域专家协作，将材料研发知识、业务流程、约束条件和验收规则沉淀为可复用的知识库、Skill、工具及智能体工作流。
3. 负责材料智能体的容器化和企业内部环境部署，持续完善数据持久化、负载均衡、高可用、灰度发布、故障恢复及环境可复现能力。
4. 建设知识、Skill、Prompt、配置及运行依赖的版本化治理能力，完善自动同步、冲突保护、变更审计和发布回滚机制。
5. 负责敏感数据处理、模型策略路由、最小权限、工具读写控制及操作审计，保障材料研发智能体在企业安全边界内合规运行。

【岗位要求】

1. 计算机、软件工程、自动化、电子信息及相关专业本科及以上学历；材料、制造相关背景可作为加分项。
2. 具备良好的系统编程、数据结构、后端架构和工程设计能力。
3. 有真实上线的 LLM/Agent、复杂工作流或 AI 模型服务系统研发经验，能够处理工具编排、任务状态、异常恢复和持续迭代等问题。
4. 熟悉 Linux 开发环境、Docker、CI/CD、配置管理和服务部署，具备发布、回滚、线上排障及性能优化能力。
5. 具有较强的业务理解、跨团队协作和独立负责能力，能够在领域知识不完整的情况下，与业务专家共同澄清需求并推动问题闭环。

## 知识点（可继续补充）

### 核心概念
- **材料研发智能体**：面向材料/制造领域的垂直 Agent，把领域知识、业务流程、约束条件、验收规则沉淀为知识库、Skill、工具和工作流。
- **智能体工作流（Agent Workflow）**：将知识、Skill、工具按流程编排为可复用的自动化工作流。
- **垂直领域 Agent**：结合领域专家知识做专业化，而非通用泛化。

### 工程化与交付
- **容器化部署**：基于 Docker 打包交付，适配企业内部环境。
- **数据持久化**：状态与数据落库，保证可恢复。
- **负载均衡 / 高可用（HA）**：多实例分流、故障自动切换，避免单点。
- **灰度发布（Canary Release）**：先小范围放量验证再逐步全量。
- **故障恢复**：服务异常后的自动恢复与重放。
- **环境可复现（Reproducibility）**：环境与依赖版本固定、可复现，避免"在我机器上能跑"。

### 治理与合规
- **版本化治理**：知识、Skill、Prompt、配置、运行依赖统一纳入版本管理。
- **治理链条**：自动同步、冲突保护、变更审计、发布回滚。
- **敏感数据处理**：脱敏、隔离、分级存储。
- **模型策略路由**：按策略（成本/质量/合规）选择合适模型。
- **最小权限（Least Privilege）**：仅授予任务所需的最少权限。
- **工具读写控制 / 操作审计**：限定工具可读写的范围，全流程留痕可审计。

### 平台与工程基础
- **Linux / Docker / CI/CD**：开发、构建与交付基础设施。
- **配置管理 / 服务部署**：支持发布、回滚、线上排障与性能优化。
- **协作与澄清**：领域知识不完整时，与业务专家共同澄清需求并推动问题闭环。
