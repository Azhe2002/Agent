# 上海它石智航技术有限公司

# AI Infra 工程师

【岗位简介】

该岗位着重于建设企业级 Agent 平台，服务于机器人数据生产、模型训练、任务编排、评测分析和研发提效等业务场景。

【岗位职责】

1. 参与公司级 Agent 平台核心模块研发，包括会话管理、上下文管理、任务状态管理、记忆机制、权限控制和异常恢复等能力。
2. 参与 Agent 执行框架与工具体系建设，支持任务规划、工具调用、插件扩展、技能编排及多步骤任务执行；面向机器人数据构建、模型训练、评测分析和任务调度等场景，设计并实现可执行的 Agent 工作流。
3. 参与 Agent 评测与可观测体系建设，对任务完成率、工具调用准确率、响应质量、稳定性和运行成本进行分析与优化。
4. 参与技术方案设计、代码开发、自动化测试和问题排查，持续提升平台的可维护性、扩展性和交付质量。

【岗位要求】

1. 计算机、人工智能、软件工程、数学、自动化等相关专业，本科及以上学历。
2. 具备扎实的编程基础，熟悉至少一门主流编程语言，能够独立完成模块开发、调试和问题定位。
3. 了解大模型应用开发，对提示词设计、结构化输出、工具调用、多轮对话等基本机制有一定理解。
4. 了解 Agent 的基本组成和运行方式，对任务规划、上下文管理、记忆机制、工具系统等概念有基础认知。
5. 掌握数据结构、操作系统、计算机网络、数据库等基础知识，具备良好的工程实践意识。
6. 具备较强的问题拆解、学习和沟通能力，能够快速理解复杂业务并推动方案落地。

【加分项】

1. 有完整的 Agent、大模型应用或复杂软件系统项目经验。
2. 有知识检索、文档理解、长期记忆、上下文优化等相关实践经验。
3. 了解前后端开发、数据库、任务调度、日志监控等基础工程能力。
4. 有数据平台、模型训练平台、MLOps、自动化测试或智能体评测相关项目经历。
5. 有开源项目、科研项目、技术竞赛或高质量个人项目经验。

## 知识点（可继续补充）

### 核心概念
- **AI Infra（AI 基础设施）**：支撑 AI 应用与 Agent 平台运行的底层基础设施工程。
- **Agent 平台**：企业级平台，服务于机器人数据生产、模型训练、任务编排、评测分析、研发提效等场景。

### 平台核心模块
- **会话管理（Session Management）**：管理用户会话的创建、保持与销毁。
- **上下文管理**：维护与传递对话/任务上下文。
- **任务状态管理**：跟踪任务的执行状态与进度。
- **记忆机制**：短期/长期记忆。
- **权限控制**：访问控制与操作授权。
- **异常恢复**：失败后的重试与恢复。

### Agent 执行框架与工具
- **任务规划 / 工具调用**：Agent 拆解任务并调用外部工具。
- **插件扩展（Plugin）**：通过插件动态扩展能力。
- **技能编排（Skill Orchestration）**：组合多个技能完成复杂任务。
- **多步骤任务执行**：按顺序/依赖执行多个步骤。
- **Agent 工作流（Agentic Workflow）**：可执行的自动化工作流定义。

### 评测与可观测
- **核心指标**：任务完成率、工具调用准确率、响应质量、稳定性、运行成本。

### 大模型应用基础
- **提示词设计（Prompt Design）**：设计引导模型行为的提示词。
- **结构化输出**：约束输出为 JSON 等固定格式。
- **工具调用（Tool Calling）**：模型请求调用外部函数。
- **多轮对话**：带历史上下文的连续对话。

### 基础设施知识
- 数据结构、操作系统、计算机网络、数据库等计算机基础。
- 前后端开发、任务调度、日志监控等工程能力。
- 数据平台、模型训练平台、MLOps、自动化测试、智能体评测。
