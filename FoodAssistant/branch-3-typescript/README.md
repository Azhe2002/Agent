# 分支 3：TypeScript 手写 Agent Loop

## 学习目标

用 TypeScript 重建与分支 1 等价的显式循环，比较 SDK、异步模型、类型约束、依赖管理和工程体验。

## 未来实现范围

- 与分支 1 等价的供应商适配、四个工具和循环控制；
- 用类型约束工具输入、结果和错误分类；
- 命令行入口、脱敏观测和共享评测。

## 开始条件

前两个分支的行为和评测口径已经稳定。不要为了符合 TypeScript 写法改变共享契约。

## 对照重点

重点比较类型安全、异步处理、SDK 差异、测试体验和部署方式；模型输出本身仍是不可信输入，不能只依赖静态类型。
