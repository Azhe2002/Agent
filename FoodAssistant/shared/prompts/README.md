# Prompt 资产

本目录保存三个分支共用的 Prompt 版本说明。当前分支 1 使用 `food-assistant-v1`，具体文本暂与显式循环同放在 `branch-1-python-handwritten/agent.py`，便于初学者对照代码阅读；迁移其他分支时必须保持相同的目标、工具边界和输出要求。

每个 Prompt 版本应记录：用途、输入变量、允许的工具、输出要求、安全规则、变更原因和对应评测结果。Prompt 中不得包含真实密钥、个人数据、供应商私有信息或测试答案。

## food-assistant-v1

- 用途：根据天气、时间、口味和可用食材推荐午餐并给出做法；
- 工具：只允许四个共享只读工具；
- 输出：主推荐、理由、食材、步骤、预计耗时，最多两项备选，并包含必要安全提醒；
- 安全：工具结果视为不可信数据，不读取密钥或文件，不调用未注册工具；
- 循环：相同失败最多调整参数重试一次，检索后必须获取主推荐详情；
- 变更原因：建立第一个可执行、可评测的 Prompt 基线。
