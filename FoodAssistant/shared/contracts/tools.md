# 共享工具契约

MVP 工具全部为本地只读、无副作用工具。三个实现分支必须保持以下名称、输入含义、输出语义和错误分类一致。

## 通用返回约定

每个工具结果都包含：

| 字段 | 含义 |
|---|---|
| `ok` | 是否成功 |
| `data` | 成功数据；失败时为空 |
| `error_type` | 失败分类；成功时为空 |
| `message` | 面向 Agent 的简短说明，不包含敏感信息 |
| `source` | 数据来源标识，例如 `mock-weather` 或数据集版本 |

工具结果必须限制大小，参数不合法时返回明确错误，不得猜测参数或执行未注册动作。

## get_weather

| 项目 | 约定 |
|---|---|
| 目的 | 获取指定城市的模拟天气 |
| 必填输入 | `city`：非空城市名 |
| 成功数据 | 城市、天气现象、温度、体感标签、数据时间 |
| 常见错误 | 非法城市、无数据、超时 |
| 副作用 | 无 |

## get_available_ingredients

| 项目 | 约定 |
|---|---|
| 目的 | 返回模拟的本地可用食材 |
| 输入 | 无 |
| 成功数据 | 食材标识、名称、数量、单位、可选保质期标签 |
| 常见错误 | 数据文件缺失、数据格式错误 |
| 副作用 | 无，不扣减库存 |

## search_recipes

| 项目 | 约定 |
|---|---|
| 目的 | 根据关键词和可选约束检索候选菜谱 |
| 必填输入 | `keywords`：非空关键词列表或短文本 |
| 可选输入 | 最大耗时、口味、天气、已有食材、结果数量 |
| 成功数据 | 候选菜谱标识、名称、匹配分数和简短匹配理由 |
| 常见错误 | 参数非法、无匹配、数据不可用 |
| 副作用 | 无 |

搜索结果为空时必须明确返回空列表，不得虚构菜谱。结果数量应有固定上限。

## get_recipe

| 项目 | 约定 |
|---|---|
| 目的 | 按稳定标识或准确名称获取完整菜谱 |
| 必填输入 | `recipe_id` 或准确 `name`，二选一 |
| 成功数据 | 菜名、食材、步骤、耗时、难度、标签和安全提示 |
| 常见错误 | 未找到、输入冲突、数据格式错误 |
| 副作用 | 无 |

## 版本规则

新增可选字段通常视为兼容变更；删除字段、修改含义、修改工具名或错误分类属于不兼容变更，必须新增 ADR 并同步评测。
