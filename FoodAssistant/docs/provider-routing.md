# 模型供应商与费用策略

## 设计结论

默认供应商为 NVIDIA。候选顺序记录为 NVIDIA → MiMo → DeepSeek → Kimi，但这个顺序只是可选路由顺序，**不代表默认自动回退**。

各供应商的模型 ID、配额、价格和能力可能变化，因此全部通过本地配置维护，不写死在共享业务契约中。

## 安全默认值

- `PAID_FALLBACK_ENABLED=false`；
- `MAX_REQUEST_BUDGET_CNY=0`；
- 缺少密钥、认证失败或配置错误时直接停止并提示用户；
- 不把认证错误伪装成普通模型失败；
- 不在日志中记录请求头、密钥、完整响应或供应商控制台链接中的敏感参数。

## 允许回退的条件

只有用户显式开启付费回退并设置大于零的单次预算后，才可按顺序尝试其他供应商。仍需满足：

1. 当前错误属于可恢复错误，例如短期限流或服务不可用；
2. 目标供应商已配置且模型具备所需的工具调用能力；
3. 预计费用不超过单次预算；
4. 运行摘要明确显示发生了供应商切换；
5. 每个供应商最多尝试有限次数，避免级联重试。

## 不应自动回退的情况

- 密钥缺失、认证失败或权限不足；
- 用户输入或工具参数不合法；
- 已达到预算、最大步骤或总超时；
- 安全策略拒绝请求；
- 模型给出低质量答案但没有明确的系统错误。

## 比较实验要求

比较三个实现分支时应固定供应商、模型、数据集、提示词版本和参数。比较供应商时则固定实现分支。这样才能知道差异来自哪里。
