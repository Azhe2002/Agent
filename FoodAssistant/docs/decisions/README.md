# Architecture Decision Records

ADR 用于记录重要设计选择及其原因，避免项目迭代后只看到结果、看不到取舍。

命名格式：`NNNN-short-title.md`。状态可使用“提议、已接受、已替代、已废弃”。已有 ADR 不直接改写结论；方向变化时新增 ADR 并互相链接。
