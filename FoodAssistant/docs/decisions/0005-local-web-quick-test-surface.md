# ADR 0005：分支 1 使用本地标准库 Web 测试入口

- 状态：已接受
- 日期：2026-09-01

## 背景

分支 1 已有可运行的命令行入口，但快速人工验证输入、最终回答和脱敏运行摘要时，命令行不够直观。当前需求只需要本地测试界面，不需要生产级 Web 服务、账号或会话。

## 决策

在 `branch-1-python-handwritten/web/` 增加一个无第三方依赖的单页界面和 Python 标准库 HTTP 适配层。适配层只负责验证单条输入、调用现有 `HandwrittenAgent` 并返回最终回答与脱敏摘要；Agent 编排、工具契约和供应商策略保持不变。

服务固定监听回环地址，静态资源使用显式白名单，不提供任意文件读取；请求有大小限制和并发上限，不持久化用户输入、回答或模型载荷。

## 影响

- 优点：无需安装前端或 Web 框架即可完成可视化联调，仍能看清 branch1 的执行边界；
- 代价：不支持流式输出、跨会话历史、生产部署与多用户并发；
- 安全边界：页面与接口同源，仅返回最终结果和聚合指标，配置与凭据不进入浏览器；
- 测试边界：HTTP 测试注入离线 runner，不访问任何外部模型 API 或真实密钥。
