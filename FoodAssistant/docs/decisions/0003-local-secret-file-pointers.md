# ADR 0003：本地密钥使用文件指针

- 状态：已接受
- 日期：2026-08-26

## 背景

本地已有被 Git 忽略的 `APIKEY/` 密钥文件。如果再把真实值复制进 `.env`，会增加明文副本、误提交和日志泄漏风险；同时，自动化 Agent 不应读取或搬运密钥内容。

## 决策

本地 `.env` 只保存 `*_API_KEY_FILE` 指针。未来的运行时加载器负责从白名单文件读取单行密钥，并保证值只在进程内存中存在。直接 `*_API_KEY` 变量仅用于用户手动配置的系统环境、CI 或密钥管理服务。

同一供应商的直接变量与文件指针不得同时设置。指针解析后的规范路径必须位于仓库根目录 `APIKEY/`，且文件名必须在供应商白名单内。

## 影响

- 优点：不复制真实密钥；Codex、Claude 和 Git 不需要接触密钥值；本地轮换只修改原密钥文件。
- 代价：常规 dotenv 库不会自动解析 `_FILE`，三个实现分支都需要一个很小的安全加载器。
- 约束：加载器不得记录密钥、密钥片段、文件内容或认证请求头；格式错误只返回脱敏错误类别。
