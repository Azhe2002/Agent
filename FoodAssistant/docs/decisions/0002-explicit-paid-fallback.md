# ADR 0002：付费模型回退必须显式开启

- 状态：已接受
- 日期：2026-08-25

## 背景

项目计划按 NVIDIA、MiMo、DeepSeek、Kimi 的顺序提供模型选择。自动回退能提升可用性，但也可能让认证错误或临时故障变成意外费用。

## 决策

默认只使用显式选择的供应商。任何可能产生费用的自动回退默认关闭，只有用户主动开启并设置单次预算后才允许执行。认证、权限、配置和安全错误禁止自动回退。

## 影响

- 优点：费用可控，错误原因透明，适合初学者。
- 代价：默认可用性低于无条件自动回退。
- 后续：如增加真实计费，应记录供应商、模型、估算费用和切换原因，但不得记录密钥。
