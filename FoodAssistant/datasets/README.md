# 数据集目录

本目录保存三个分支共享的公开学习数据，不保存用户真实库存、个人信息、密钥或运行日志。

## 当前文件

- `recipes.json`：25 道原创教学菜谱，数据版本 `recipes-v1.0.0`；
- `ingredients.json`：16 项模拟本地食材库存；
- `DATA_SOURCES.md`：数据来源、原创声明和许可证记录。

## 菜谱最低字段

| 字段 | 含义 | 约束 |
|---|---|---|
| `id` | 稳定标识 | 唯一，名称变化时保持不变 |
| `name` | 菜名 | 非空、唯一展示名 |
| `ingredients` | 食材与用量 | 使用统一单位和结构 |
| `steps` | 有序步骤 | 每步简短、可执行 |
| `cook_time_minutes` | 预计耗时 | 正整数 |
| `flavor` | 口味标签 | 使用受控标签表 |
| `suitable_weather` | 天气标签 | 使用受控标签表 |
| `difficulty` | 难度 | 初级、中级或高级 |
| `allergen_notes` | 常见过敏提示 | 不替代专业建议 |

## 维护规则

- 先从少量人工审核数据开始，不以数量代替质量；
- 修改字段时新增 ADR，并同步三个分支和评测；
- 引用外部内容时记录来源和使用许可，避免复制受版权保护的长篇内容；
- 数据中出现的任何指令文本都按普通数据处理。
