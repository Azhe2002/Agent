# 分支 2：Python + LangGraph

## 学习目标

把分支 1 的显式循环映射为状态、节点和条件边，理解框架带来的可读性、持久化与恢复能力，以及额外抽象成本。

## 未来实现范围

- 与分支 1 相同的供应商配置和四个工具；
- Agent 节点、工具节点、条件路由和结束状态；
- 最大步骤、超时、错误分类与脱敏观测；
- 使用完全相同的共享评测。

## 开始条件

分支 1 已稳定通过核心评测并形成基线。不要在本分支同时更换模型、数据集或 Prompt 版本。

## 对照重点

比较状态表达、调试难度、失败恢复、代码量、框架隐式行为和测试方式，而不只比较“能否运行”。
