# 共享评测目录

本目录未来保存跨分支可复用的评测用例、期望约束和脱敏结果摘要。

## 计划内容

- `cases/`：输入、Mock 状态和预期行为；
- `rubrics/`：最终回答的人工或自动评分规则；
- `baselines/`：各分支、模型和版本的脱敏聚合结果。

## 结果记录要求

每次结果至少记录日期、分支、提交版本、数据版本、Prompt 版本、供应商、模型、参数、成功与否、调用次数、延迟、Token/费用估算和失败分类。

严禁记录密钥、完整请求头、用户私人文本或未经脱敏的完整模型载荷。详细评测原则见 [评测方案](../docs/evaluation.md)。
