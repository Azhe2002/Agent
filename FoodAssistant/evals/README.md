# 共享评测目录

本目录保存跨分支可复用的评测用例、期望约束和脱敏结果摘要。

## 当前内容

- `cases/core.json`：10 个核心场景及预期行为；
- `baselines/branch-1-nvidia-smoke.md`：分支 1 首次成功 NVIDIA 真实冒烟结果及局限；
- 自动评分规则暂由 [评测方案](../docs/evaluation.md) 和用例字段共同定义，稳定后再拆出 `rubrics/`。

## 结果记录要求

每次结果至少记录日期、分支、提交版本、数据版本、Prompt 版本、供应商、模型、参数、成功与否、调用次数、延迟、Token/费用估算和失败分类。

严禁记录密钥、完整请求头、用户私人文本或未经脱敏的完整模型载荷。详细评测原则见 [评测方案](../docs/evaluation.md)。
